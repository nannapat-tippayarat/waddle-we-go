# 🐧 Waddle We Go?

Turning penguin journeys into stories that help young people understand Southern Ocean biodiversity research and why conservation must extend beyond where animals live.

## 🌊 About the Project

Waddle We Go? is an interactive website that explores the journeys of eight juvenile emperor penguins tracked in the Southern Ocean from 2019 to 2020.

Explore their journeys on an interactive map, filter by penguin and month, and learn about Antarctica's changing seasons.

## 💻 Built With

- React
- Vite
- React Leaflet
- Leaflet

## 🚀 Run Locally

1. Clone the repository.
2. Open the project folder in your terminal.
3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the localhost URL shown in your terminal.

## 🧊 Research

Penguin tracking research: https://doi.org/10.1098/rsos.211708

Tracking points are satellite observations. Lines connecting them are visual approximations, not confirmed exact travel paths.
